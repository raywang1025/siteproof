# Example reports

- `sample-report.md` is a real Markdown export from a public Taneverse audit.
- `sample-report.json` is a JSON export from SiteProof's deliberately broken
  local fixture.

Base64 screenshots were removed from the JSON example to keep the repository
small. Reports generated by the Extension include screenshot data in the local
JSON export.

Example findings are evidence captured at one moment. They are not permanent
claims about the audited website.
