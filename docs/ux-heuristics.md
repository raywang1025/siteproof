# UX heuristics in SiteProof

SiteProof references
[Jakob Nielsen’s 10 usability heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)
as an organizing framework for potential usability risks.

SiteProof is an independent open-source project. It is not affiliated with or
endorsed by Nielsen Norman Group, and a SiteProof report is not an NN/g
certification.

## Three evidence levels

| Level | Meaning |
| --- | --- |
| Confirmed issue | Browser or DOM evidence directly demonstrates the problem. |
| Potential UX risk | Evidence is relevant to a heuristic, but user impact is inferred. |
| Needs user testing | A real participant must attempt the task before making the claim. |

The default task is:

> A first-time visitor can understand what the site offers, find the key
> information, and identify the primary next step.
